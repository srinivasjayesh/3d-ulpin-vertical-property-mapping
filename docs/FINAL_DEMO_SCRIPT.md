# Final Demo Script

1. Start the API and open the browser. Show the profile selector and the provenance note.
2. In Hyderabad, select B0595, then B0612 and B0589. Point out source height, parcel match and confidence label.
3. Switch Building → Floor → Unit. Explain that floor strata are equal-height and IDs are prototype IDs.
4. Use Ward 3D and the surrounding 2D map. Use Show Below Ground and state that B1/B2 is derived demonstration geometry, not a basement survey.
5. Search a building/floor/unit ID and show the selected record in the left details panel.
6. Switch to Manhattan. Show a source building, generated units and the explicit limitation that PLUTO basement codes do not produce basement geometry.
7. Switch to Mumbai. Show the official G/South boundary, OSM roads and source-derived strata; note that unknown levels remain unknown and units/basements are zero.
8. Open /api/system/capabilities and /docs to show optional PostGIS, DEM, BIM and LiDAR paths.
9. Close with the business framing: a provenance/vertical workflow layer that can complement a city-scale GIS programme.
